# 出題・採点ロジック

この文書は仕組みの概要です。厳密な計算式は [採点・理解度・復習ルール](../参照資料/採点・理解度・復習ルール.md)、Markdownの制約は [セッション形式](../参照資料/セッション形式.md)、正式な語句名は [分類表](../参照資料/出題分類と概念カタログ.md)を正本とします。

## 出題アルゴリズム

初回は診断フェーズとして、既定で8問をWeb、ネットワーク、暗号、認証、PKI、DNS、メール、マルウェアから1問ずつ出します。難易度はLevel 2〜3を中心にし、最初から得意・不得意を決めつけません。通常Sessionは6問です。

通常時は、おおむね次の配分で候補を選びます。

| 枠 | 目安 | 目的 |
|---|---:|---|
| 弱点 | 2問 | 低理解度の基礎を説明し直す |
| 復習期 | 1問 | 忘れ始める時期の想起練習 |
| 新規 | 2問 | 前提関係と頻出度に沿って範囲を広げる |
| 発展 | 1問 | 得意分野を比較・ログ・シナリオ問題へ進める |

7問以上を指定した通常Sessionでは、この6問構成を保ち、追加した全問題を新規枠にする。弱点中心・新規中心・科目B寄りなどを明示したときは、その指定を優先する。

優先度には、弱点度、復習期限からの経過、科目B重要度、未学習ボーナス、最近の分野偏り、弱い概念との関連性、分類表の`Importance`を使います。`Importance`は4倍して加点するため、同程度の新規候補なら重要度5の頻出・基礎語を先に扱います。ただし低得点の弱点や期限超過の復習は優先度を上回れるため、重要語への偏りは防ぎます。同日に正解した概念や直近Sessionで扱った語句には再出題抑制を掛けます。通常の理解・応用問題では、科目B形式を原則70〜85%（6問なら5問）にします。科目B形式は、短いログ・設定・構成・運用手順・攻撃経路を示し、「何を確認するか」「原因・影響は何か」「どの対策を優先するか」を判断させる形式です。単なる「説明してください」型は科目B形式に数えず、純粋な説明問題は通常1問までにします。単純なランダム抽出は行いません。

### 暗記語句問題の選択

暗記語句問題はAを `floor(問題数 × 40%)`、Bを残りとして厳密に配分します。両TrackともLevel 1の短い語句説明形式です。

選択には総合理解度、Attempts、Last Studied、Last Score、Next Review、忘却度、関連語句、最近の出題を使います。通常説明の弱点度・出題難易度・発展判定には `Explanation Score`、暗記語句の弱点度・定着判定には `Recall Score` を使い、自己モードが未評価なら新規候補として扱います。

日々の出題候補は`出題分類と概念カタログ.md`と`進捗/`だけから選びます（最近のSessionは問題文重複の確認だけに使います）。初回の151語すべてに`Recall Attempts`が1回以上付いたら、次の暗記語句Sessionを作る前にIPAの最新シラバスと過去問PDFを分析し、頻出テーマ・候補語句・根拠年度を`過去問分析索引.md`へ記録します。その上で未登録の重要語を80〜120語追加して約250語に広げます。約250語を1周した後も同じ分析を行い、過去問で具体的に不足が判明した場合だけ20〜40語ずつ追加します。通常問題の`Explanation Attempts`だけでは1周と見なさず、`わかりません`を含む採点済み暗記回答は1回として数えます。

通常説明の低得点は暗記候補へ、暗記語句の低得点は通常説明候補へ加点します。`Score` は両形式を統合し、モード別Scoreは「暗記はできるが応用が弱い」などの差を残します。

## 採点と理解度更新

通常問題は、問題が要求する観点だけを次から選び、配点を100点へ正規化して意味ベースで採点します。

1. 定義
2. 原理
3. 成立条件
4. 攻撃・利用シナリオ
5. 対策とその理由
6. 類似概念との差・限界

暗記語句問題は、基本定義だけを100%で評価します。「クラウドの提供側と利用者側で責任を分担すること。」のように一文で核を正しく言えれば満点です。目的・特徴・仕組み、具体例、シナリオ適用、高度な対策がないことでは減点しません。

「採点して」は全Sessionの回答内容を確認し、全回答済みで未採点または進捗更新未完了のSessionを日付・Session番号の昇順で処理します。`awaiting_answers`や`ready_for_grading`といったStatusは対象選択に使いません。空欄があるSessionは飛ばすため、新しい未回答Sessionが古い回答済みSessionの採点を妨げません。

採点後は問題別の結果をSessionへ追記し、補助スクリプトが `語句別理解度.md`、`分野別理解度.md`、`学習履歴.md` を冪等に更新して、最後にSessionを `graded` にします。更新前にMode、保存先、Question Count、Q番号、必須メタデータを検証し、不一致は自動補正せずprogress更新前に停止します。

低難易度での満点だけで応用力100とは見なさず、Level 1〜4の証拠スコアには上限を設けます。Recall ScoreとSession平均は0〜100の生点を保持し、総合理解度と分野スコアの直近証拠へ反映するときだけLevel 1の証拠上限を適用します。

## 復習タイミング

基本間隔は現在理解度に応じて1日、2日、5日、12日、30日です。直近の点数、出題難易度、連続した理解の安定性で補正します。直前と今回がともにLevel 5以上の高得点の場合だけ長期安定として延長し、Level 1暗記問題の100点はこの連続成功へ数えません。

Next Reviewは両モード共通です。期限前は出しすぎず、期限が近い・過ぎた概念は忘却度を上げます。100点の概念も除外せず、応用理解まで安定していれば期間を空けて再び扱います。
