# 使い方

## Skillの起動条件

`security-specialist-trainer` は、次のような意図で使用します。

- 「問題作って」「今日の問題」「セキスペ勉強しよう」「5問出して」
- 「暗記単語問題作って」「暗記語句問題作って」「単語問題10問」「暗記問題20問作って」
- 「軽く復習」「Web系多め」「科目Bっぽく」「苦手中心」「新しい単語多め」
- 「採点して」「答え合わせして」「レビューして」
- 「今日の結果どう？」「理解度見せて」「今の弱点は？」

このリポジトリを作業場所として開けば、`AGENTS.md` がこれらの自然言語リクエストをローカルSkillへ誘導します。Skillを明示する場合は `$security-specialist-trainer` と指定します。

## 2種類の問題

### 理解・応用問題

原理、成立条件、対策とその理由、比較、ログや設定の読み取り、シナリオへの適用を説明します。通常は6問（弱点2問、復習1問、新規2問、発展1問）です。7問以上を指定した場合、6問を超える分はすべて新規問題にします。初回の診断では、指定がなければ8分野から1問ずつ出題します。

作成先は `sessions/理解・応用問題/YYYY-MM-DD.md` です。

### 暗記語句問題

提示された語句について「何であるか・何のためか・重要な特徴」を短く説明する想起練習です。指定がなければ10問、指定時は1〜30問です。Aは `floor(問題数 × 40%)`、Bは残りとし、10問ならA4/B6です。両TrackともLevel 1の短い「○○とは何ですか？」形式を維持します。

各問題の `Primary Terms` は1語句に限定します。taxonomy上の複合名称は1語句として扱います。

作成先は `sessions/暗記語句問題/YYYY-MM-DD.md` です。

## 学習の流れ

1. チャットで「問題作って」または「暗記語句問題作って」と依頼する。
2. 作成されたSessionの各 `### 回答` の下へMarkdownで回答を書く。
3. チャットで「採点して」と依頼する。全回答済みで未採点のSessionは、古い順にすべて処理される。`awaiting_answers`のままでも、回答内容がそろっていれば対象になる。
4. 問題別の採点と3つのprogressファイルが更新される。空欄を含むSessionは飛ばされ、未回答の問題番号だけが通知される。
5. 必要に応じて `復習用/流れ図/` にMermaid図解が追加される。
6. 翌日以降、再び問題を作成する。過去の結果と復習期限が次の選択へ反映される。

分量や傾向は自然文で変更できます。例: 「今日は3問」「Web系を多めに」「新しい概念多め」「科目Bのログ分析っぽく」「暗記語句問題を20問」。指定できる問題数は、どちらのモードも1〜30問です。

## 回答と採点結果

問題文やメタデータは変更せず、各 `### 回答` 見出しの下へ回答を書きます。理解・応用問題、暗記語句問題のいずれでも、思い出せない場合は空欄ではなく `わかりません` と記入します。この記入は回答済みとして `0 / 100` で採点され、復習対象として履歴に反映されます。採点対象はStatusではなく回答内容で決まり、全回答済みで進捗更新まで完了していないSessionを古い順に処理します。採点後は、点数、良かった点、足りない点、短い模範説明、次回確認する観点が同じSessionへ追記されます。

詳しいSession形式は [セッション形式](../references/session-format.md)、評価基準は [採点・理解度・復習ルール](../references/scoring-rules.md)を参照してください。
