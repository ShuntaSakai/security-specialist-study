# 情報処理安全確保支援士・適応学習ノート

情報処理安全確保支援士試験（セキスペ）の科目A・科目Bを、Markdownで記録しながら反復学習するためのリポジトリです。短い暗記語句問題による想起と、理解・応用問題による原理・条件・対策・シナリオの説明を相互に補強します。

## 使い始める

1. このリポジトリを作業場所として開く。
2. チャットで「問題作って」または「暗記語句問題作って」と依頼する。
3. 作成されたSessionの各 `### 回答` の下へ回答を書く。
4. チャットで「採点して」と依頼する。

「採点して」は、回答がすべて埋まっていて採点・進捗更新が未完了のSessionを、`Status`表記に依存せず古い順にすべて処理します。空欄のSessionは飛ばして未回答番号だけを知らせます。

通常は理解・応用問題を6問、暗記語句問題は10問作成します。理解・応用問題は弱点2問、復習1問、新規2問、発展1問が既定で、7問以上を指定した場合の追加分はすべて新規問題です。問題数、分野、科目B寄り、弱点中心などは自然文で指定できます。

暗記語句カタログは、IPAの試験シラバスと過去問を基準に18分野・151語まで広げています。頻出性・科目Bでの説明必要性・前提度が高い重要度5の語句は、未学習の同程度の候補より優先して出題します。ただし、弱点や復習期限の語句は優先して取りこぼさない設計です。日々の出題は`参照資料/taxonomy.md`と`進捗/`を根拠に行い、151語を暗記語句問題で1周した後だけ過去問PDFを分析して、80〜120語を追加して約250語に広げます。約250語を1周した後も同様に分析し、不足が見えた場合だけ20〜40語ずつ追加します。

IPAの問題冊子・解答例・採点講評は、ローカルの`過去問/`へ保存できます。このディレクトリはGit管理外です。PDFを分析した結果は[過去問分析索引](参照資料/past-question-index.md)へ軽く保存し、カタログ拡張時はまずこの索引を使います。チャットで「過去問を参照して」と明示された場合は、索引だけで済ませずPDFそのものも確認します。

答えが思い出せないときは、理解・応用問題、暗記語句問題のどちらでも空欄にせず `わかりません` と記入してください。未回答として止めず、0点と復習ポイントを記録します。

学習履歴の正本は `学習記録/` と `進捗/` の人が読めるMarkdownです。出題候補の選択と採点結果の反映には、リポジトリ内の `security-specialist-trainer` Skillを使用します。

採点で得た再利用可能な補足は、[復習用/学んだこと/README.md](復習用/学んだこと/README.md)から分野別ノートとして確認できます。追記分には記入日を残し、同じ分野・同日のメモは一つの日付見出しにまとめます。処理の流れは [復習用/流れ図/](復習用/流れ図/) に分けて保存します。

採点した翌日に見直す項目は、[復習用/明日復習するべきところ/README.md](復習用/明日復習するべきところ/README.md)に案内する日付別のチェックリストへまとめます。100点以外の回答は、暗記・理解を問わず対象で、元の問題を開かなくても復習できる短い解説と、関連する新語を一つ付けます。
